# Melody, Counterpoint & Polyphonic Listening - deployment package

This folder is ready to be used as the root of a GitHub Pages repository.

## Public deployment

Upload `index.html` and `README.md` to the repository root and enable GitHub Pages from the main branch/root folder.

## Companion Ubi caritas recordings

The Chapter 6 manuscript now contains a three-way comparative listening case study (Gregorian chant / Durufle / Gjeilo). The public lab package intentionally does **not** include those recordings yet.

- The Durufle and Gjeilo compositions remain copyright-protected.
- Recording/master permissions and composition/publisher permissions are separate.
- Add public audio URLs only after rights clearance, or link to authorized third-party recordings instead of hosting the files.

Once cleared, the manuscript's `audio_links.tex` contains keys `ubi_gregorian`, `ubi_durufle`, and `ubi_gjeilo` that can be assigned stable HTTPS URLs without changing the chapter prose.
